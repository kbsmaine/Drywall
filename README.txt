CONTACT FORM
The quote form currently sends to:
krpelletier33@gmail.com

The address appears in two places inside contact.html:
1. form action="https://formsubmit.co/EMAIL"
2. data-email-endpoint="https://formsubmit.co/ajax/EMAIL"

Replace both instances to change the receiving email. FormSubmit may send a one-time activation email the first time the form is used. Open that email and confirm it before submissions will be delivered.

DEPLOYMENT
Upload the entire folder contents to the root of a GitHub repository, then enable GitHub Pages from the repository settings. Keep the folder structure unchanged.
